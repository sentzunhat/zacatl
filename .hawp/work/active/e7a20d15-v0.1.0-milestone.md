# v0.1.0 milestone — all platforms to a minimal standard

**UUID:** `e7a20d15` · **Type:** milestone · **Priority:** P1 · **Reported:** 2026-07-17
**Rescoped:** 2026-07-29

**Owner direction:** "version 0.1.0 is where I want all the providers at least working to a
minimal standard — the CLI, the desktop, and server — all working platforms. It doesn't have
to be fast. It can be a long road map."

---

## Definition of done per platform

### Server (already mature — keep green)

Fastify + Express adapters, three ORMs (Mongoose, Sequelize, node:sqlite), page serving,
full CRUD examples, docker smoke matrix. Remaining: keep CI green through v0.1.0 cut.

### CLI (new work)

`ServiceType.CLI` boots, registers commands from `layers.application.entryPoints.cli`,
executes a command end-to-end. Needs: real example under `examples/`, unit + smoke
coverage, docs.

### Desktop (new work)

`ServiceType.DESKTOP` boots with the Neutralino platform, IPC handlers wired from
`entryPoints.ipc`, window config honored. Needs: promote the existing experiment into
a minimal supported example, coverage, docs.
